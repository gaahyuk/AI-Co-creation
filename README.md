# 청년정책 토스 미니앱

청년이 **본인 정보로 신청 가능한 청년 정책을 맞춤 추천받고, 신청까지 돕는** 토스 미니앱.
데이터는 **온통청년 청년정책 OpenAPI**(공공데이터포털 15143273)를 사용한다.

---

## 한 줄 요약

> 내 정보(나이·지역·취업상태)를 입력하면 → 신청 가능한 정책만 골라주고 → 받을 수 있는 돈을 합산해 보여주고 → 서류 준비부터 신청 링크까지 연결해주는 앱.

---

## 핵심 차별점 (온통청년 대비)

| | 온통청년 | 이 앱 |
|---|---|---|
| 맞춤 필터 | 수동 검색 | 프로필 기반 **자동 추천** |
| 자격 확인 | 직접 읽고 판단 | **항목별 충족/미충족 자동 판정** |
| 받을 돈 | 정책마다 따로 | **신청 가능 정책 금액 합산 + 카테고리별 분해** |
| 마감 관리 | 없음 | **마감임박 정렬 + 타임라인** |
| 신청 준비 | 없음 | **서류 체크리스트 + 진행률** |

## 화면 구성

### 1. 온보딩 (4문답 진단)
나이 → 거주지(시/도→시/군/구) → 취업상태·소득 → **관심 분야** 선택
→ 마지막에 **"신청 가능 N개 / 받을 수 있는 돈 약 M만원"** 진단 리포트

### 2. 홈 (맞춤 정책 목록)
- 상단에 **"받을 수 있는 돈 약 N억"** 카드 (더보기 → 카테고리별 분해, 클릭 시 해당 탭 이동)
- 저장한 정책 중 **마감임박(D-14)** 가로 스크롤 섹션
- 탭: **⭐관심(별표 모음)** · 전체 · 일자리 · 주거 · 교육 · 복지문화 · 참여권리
  - 온보딩에서 고른 관심 분야 탭이 첫 진입 시 자동 선택
- 토글: **미충족 정책도 보기** / **⚡바로신청만**
- 정책 카드: 카테고리 · 자격 뱃지(✓자격충족/신청가능/조건확인) · ⚡바로신청 · 수령액 · 지역/전국 태그 · D-day

### 3. 정책 상세
- **내 자격 확인** 체크리스트 (연령·거주지·소득·취업상태 → 충족✓/미충족✕/확인필요)
- **예상 지원금** (금액 파싱된 경우만 표시)
- 정책 설명 · 지원 내용 · 신청 방법
- **서류 준비 체크리스트** (체크박스 + 진행률 바, 저장됨)
- 참고 링크 · 신청 기간
- 하단: **★저장** / **신청하러 가기**(홈페이지 수준 링크는 "신청 사이트로 가기" + 안내)

### 4. 저장함
- 마감 가까운 순 정렬, D-7 이내 빨강 강조
- 각 정책 서류 준비율 표시

## 추천·필터·정렬 로직

### 자격 판정 (4개 항목)
- **연령**: 정책 연령범위 vs 내 나이 (`0~0` 또는 제한없음 = 충족)
- **거주지**: 정책 지역코드에 내 지역 포함 여부 (전국 정책 = 충족)
- **취업상태**: 정책 대상 코드에 내 상태 포함 (`0013010=제한없음` = 충족)
- **소득**: 단위가 불명확해 **제외 기준 아님**, 안내만 ("소득 조건 없음"이면 충족)
- "제한 없음/조건 없음/전국"은 모두 **충족(✓)** 으로 평가

### 필터
- **지역**: 시/도만 선택 시 그 시/도 전체 시군구 코드를 API에 전달 (시군구는 5자리만 인식)
- **카테고리·키워드·지역**: 온통청년 API 서버에서 직접 필터링
- **나이·취업상태·관심분야·바로신청·신청가능**: BFF에서 후처리 필터링
- **마감된 정책**(종료일 경과)은 기본 화면에서 자동 제외

### 정렬 (적격 우선 → 아래 순서)
1. ⏰ **마감임박** (D-14 이내, 임박한 순)
2. ✓ **자격충족** (4항목 전부 ✓, 금액 높은 순)
3. 💰 **지원금 있음** (금액 높은 순)
4. 나머지 (지역 전용 우선)

### "받을 수 있는 돈" 추정
- 지원내용 텍스트에서 금액 파싱 (만원 단위)
- `억원`·"예산" 문맥 제외, "월 N만원 × 최대 M개월"은 기간 반영(없으면 ×12, 12개월 캡)
- 항상 **"추정치"** 로 표기

## 기술 스택 / 아키텍처

```
[토스 앱 WebView]
   └ 미니앱 번들 (React/Next.js → 콘솔 업로드 → 토스 CDN)
        ↕ HTTPS
[BFF 서버 (Next.js API Routes / Vercel)]   ← API 키 보호
        ↕                    ↕
  온통청년 OpenAPI      apps in toss API
```

- **프론트+BFF**: Next.js 16 (App Router) + React 19 + TypeScript
- **데이터**: 온통청년 `GET /go/ythip/getPlcy` (JSON, 약 2,600건)
- **상태**: localStorage (프로필·북마크·서류 체크), API 응답 1시간 캐싱
- **테스트**: Vitest (자격판정·금액파싱·지역범위 등 26개)
- **API 키**: `.env.local`에만 보관 (gitignore, 클라이언트 번들 미포함)

### 주요 파일
```
src/
├── app/
│   ├── page.tsx                  홈 (목록·머니카드·필터·정렬)

│   ├── policy/[plcyNo]/page.tsx  상세 (자격·지원금·서류체크)
│   ├── saved/page.tsx            저장함 (마감 타임라인)
│   └── api/policies/             BFF 엔드포인트
├── lib/
│   ├── youth/
│   │   ├── client.ts             온통청년 API 호출·페이지 수집
│   │   ├── eligibility.ts        자격 판정·지역범위·D-day
│   │   ├── money.ts              지원금 텍스트 파싱
│   │   ├── transform.ts          API 응답 정규화
│   │   └── types.ts
│   ├── regions.ts                시/도·시군구 코드, 취업상태, 카테고리
│   ├── storage.ts                localStorage 훅 (프로필·북마크·서류)
│   └── format.ts
```

## 알려진 한계 / 향후 과제

- **소득 정밀 매칭**: API의 소득 기준 단위(연소득/중위소득)가 코드마다 달라 현재 미반영
- **지원금 추정**: 텍스트 파싱 기반이라 100% 정확하지 않음 ("추정" 표기)
- **취업상태 코드 라벨**: 데이터 분포로 추정 (공식 코드정의서 검증 권장)
- **푸시 알림**: 앱인토스 SDK 연동 후 가능 (현재는 앱 내 마감임박 표시까지)
- **토스 사용자 정보 자동 연동**: 현재 직접 입력, SDK 연동 시 나이·연락처 자동화
