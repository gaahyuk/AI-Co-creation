Policy-Match 프로젝트 개발 기획서

1. 프로젝트명

Policy-Match: 청년 정책 매칭 플랫폼

2. 한 줄 요약

청년의 개인 정보를 기반으로 최적의 정책을 추천하는 AI 기반 정책 매칭 플랫폼

3. 프로젝트 개요

3.1 프로젝트 설명

Policy-Match는 정부에서 제공하는 청년 정책 정보를 수집·분석하여 사용자의 개인 정보(나이, 거주 지역, 직업, 소득 등)와 매칭하는 AI 기반 정책 추천 서비스입니다.

사용자는 본인에게 맞는 정책을 쉽게 찾고, 신청 과정을 단계별로 지원받을 수 있으며, 필요한 서류를 사전에 준비할 수 있습니다.

3.2 핵심 가치

  • **시간 절약**: 수천 개의 정책 중 관련 정책만 자동으로 필터링
  • **정확한 추천**: 사용자 조건에 정확히 맞는 정책 제시
  • **통합 관리**: 저장된 정책의 진행 상황을 한 곳에서 추적
  • **신청 안내**: 각 정책별 신청 방법 및 필요 서류 안내

    • 4. 배경 및 필요성

    4.1 현황

  • **정책 수**: 온통청년 API를 통해 2,637개의 청년 정책 제공 중
  • **문제점**:

    • - 청년이 본인에게 맞는 정책을 찾기 어려움

    - 정책 정보가 분산되어 있음

    - 신청 기한을 놓치는 경우가 많음

    4.2 타겟 사용자

  • **주 사용자**: 19-34세 청년
  • **세부 그룹**:

    • - 미취업자 / 구직자

    - 신입사원 / 사회초년생

    - 자영업자 / 프리랜서

    - 창업 희망자

    4.3 필요성

    정책 정보의 효율적 제공으로 청년의 정책 접근성 향상 및 실질적 혜택 제공

    ctx: RouteContext<"/api/policies/[id]/detail">

    // 수정 후

    type Props = { params: Promise<{ id: string }> };

    export async function GET(req: Request, props: Props) {

    const { id } = await props.params;

    ```

  • **우선순위**: 즉시 처리

    • 9.2 높음 우선순위
