# 청년정책 토스 미니앱 설계 문서

**날짜:** 2026-06-04  
**상태:** 승인됨

---

## 배경 및 목적

온통청년 청년정책 OpenAPI를 활용해 청년들이 본인에게 해당하는 정책을 쉽게 찾고, 실제 신청까지 도움받을 수 있는 토스 미니앱을 출시한다. 기존에 정책 정보가 여러 사이트에 분산되어 있고 본인 해당 여부 확인이 어렵다는 문제를 해결한다.

---

## 핵심 가치

> 내 정보를 입력하면, 지금 당장 신청 가능한 청년 정책만 보여주고, 신청까지 도와준다.

## 기술 스택

### 프론트엔드 (토스 미니앱)
- **빌드 형태:** 웹(React) → **WebView 방식**
  - 앱인토스는 노코드 빌더가 아니라, 직접 개발한 앱에 토스 SDK를 연동해 빌드 번들을 콘솔에 업로드하는 구조다.
  - 정적 웹 번들이 토스 CDN 업로드 모델과 가장 잘 맞고, BFF(Next.js)와 스택을 공유하므로 WebView 방식을 채택한다.
- **Framework:** React + TypeScript
- **SDK:** apps in toss WebView SDK (로그인/인증/결제 등 핵심 기능)
- **UI Library:** `@tossteam/tds` (Toss Design System) — 화면/로직은 직접 개발, TDS 컴포넌트만 활용
- **HTTP:** `fetch` / `axios`
- **상태관리:** React Query (서버 상태) + `useState` (로컬)
- **호스팅:** 빌드 번들을 앱인토스 콘솔에 업로드 → **토스 CDN에서 호스팅** (Vercel 아님)

### 백엔드 (BFF)
- **Framework:** Next.js (API Routes)
- **호스팅:** Vercel (무료 티어)
- **역할:**
  - 온통청년 API Key 보호 (클라이언트 노출 방지)
  - 사용자 프로필 기반 정책 필터링 로직
  - 응답 캐싱 (정책 데이터는 자주 바뀌지 않음)

### 외부 API & 키 관리

본 프로젝트는 **두 종류의 API 키**를 사용한다. 혼동하지 않도록 명확히 구분한다.

| 키 종류 | 발급처 | 용도 | 비고 |
|---------|--------|------|------|
| **온통청년 OpenAPI 키** | 온통청년 포털 | 청년 정책 데이터 조회 | BFF 서버에서만 사용 (클라이언트 노출 금지) |
| **앱인토스 콘솔 API 키** | apps in toss 콘솔 | 토스 플랫폼 연동(사용자 정보 등) | 발급 완료. 이름 "청년정책", **만료일 2027-06-04** |
| 토스페이 가맹점 키 | apps in toss 콘솔 | 결제 연동 | Phase 2에서 필요 시 등록 (현재 미등록) |

- **온통청년 OpenAPI (신규 청년정책 API, 공공데이터포털 15143273):**
  - **엔드포인트:** `GET https://www.youthcenter.go.kr/go/ythip/getPlcy`
  - **응답 포맷:** JSON (`rtnType=json`), 전체 약 2,608건
  - 목록과 상세가 동일 엔드포인트. `plcyNo`로 단건 상세 조회

  **주요 요청 파라미터**

  | 파라미터 | 설명 |
  |----------|------|
  | `apiKeyNm` | API 인증키 (필수) |
  | `pageNum` / `pageSize` | 페이지 번호 / 페이지당 건수 |
  | `rtnType` | 응답 포맷 (`json`) |
  | `plcyNo` | 정책 번호 (단건 상세 조회) |
  | `plcyKywdNm` | 키워드 검색 |
  | `lclsfNm` / `mclsfNm` | 대분류 / 중분류명 |
  | `zipCd` | 법정동 지역코드 (콤마 구분) |

  **주요 응답 필드 → 화면 매핑**

  | 필드 | 의미 | 사용 화면 |
  |------|------|-----------|
  | `plcyNo` | 정책 고유번호 | 키/북마크 |
  | `plcyNm` | 정책명 | 리스트/상세 |
  | `plcyKywdNm` | 키워드 | 리스트 태그 |
  | `plcyExplnCn` | 정책 설명 | 상세 |
  | `lclsfNm` / `mclsfNm` | 대/중분류 | 카테고리 탭 |
  | `plcySprtCn` | 지원 내용 | 상세 |
  | `sprvsnInstCdNm` | 주관기관명 | 리스트/상세 |
  | `bizPrdBgngYmd` / `bizPrdEndYmd` | 사업기간(마감일 D-N) | 리스트/상세 |
  | `plcyAplyMthdCn` | 신청방법 | 상세 |
  | `sbmsnDcmntCn` | 제출서류 | 상세 |
  | `aplyUrlAddr` | **신청 URL** | 신청 버튼(외부 연결) |
  | `refUrlAddr1` / `refUrlAddr2` | 참고 URL | 상세 |
  | `sprtTrgtMinAge` / `sprtTrgtMaxAge` | 지원 연령 | 자격 체크 |
  | `earnMinAmt` / `earnMaxAmt` / `earnCndSeCd` | 소득 조건 | 자격 체크 |
  | `zipCd` | 지원 지역(법정동코드) | 지역 필터 |
  | `jobCd` | 취업상태 코드 | 자격 체크 |
  | `schoolCd` / `plcyMajorCd` | 학력 / 전공 요건 | 자격 체크 |
  | `addAplyQlfcCndCn` | 추가 자격조건 | 자격 체크 |

  **필터링 전략 (검증 완료):**
  - **지역(`zipCd`)·대분류(`lclsfNm`)·키워드(`plcyKywdNm`)** → 온통청년 API 서버에서 직접 필터 + 페이지네이션. `zipCd`는 **시군구 5자리 코드**여야 작동(2자리 시도 코드는 무시됨). 시군구 코드를 보내면 해당 지역 + 전국(지역무관) 정책이 함께 조회됨.
  - **연령·소득·취업상태** → API에 필터 파라미터가 없으므로 BFF에서 응답 필드로 자격 판정(`evaluateEligibility`) 후 뱃지 부여 및 적격 우선 정렬(제외하지 않음).
  - 시군구 코드 데이터: `src/lib/regions.ts` (17개 시도 + 시군구).

**키 보안 원칙**
- 모든 키는 BFF 서버의 환경변수(`.env`, Vercel Environment Variables)로 관리
- 클라이언트(미니앱) 번들에는 어떤 키도 포함하지 않음
- 앱인토스 콘솔 키 **만료일(2027-06-04) 1개월 전 갱신** 필요 — 운영 체크리스트에 등록

## 시스템 아키텍처

프론트엔드 번들(토스 CDN 호스팅)과 API 키 보호용 BFF 서버(Vercel 호스팅)를 명확히 분리한다.

```
[토스 앱 WebView]
   └ 미니앱 번들 (React 빌드 → 콘솔 업로드 → 토스 CDN 호스팅)
        ↕ HTTPS
[BFF 서버 (Next.js / Vercel)]  ← API 키 보호
  ├── /api/policies        ← 필터링된 정책 목록     [온통청년 키 사용]
  ├── /api/policies/[id]   ← 정책 상세              [온통청년 키 사용]
  ├── /api/profile         ← 프로필 저장 (로컬 fallback)
  └── /api/toss/*          ← 토스 사용자 정보 연동    [앱인토스 콘솔 키 사용]
        ↕                              ↕
  온통청년 OpenAPI            apps in toss API
```

- **프론트 번들**은 토스 CDN에, **BFF 서버**는 Vercel에 각각 호스팅된다.
- 온통청년 키와 앱인토스 콘솔 키 모두 BFF 서버에서만 사용. 클라이언트는 BFF만 호출한다.

## 화면 구성 (Phase 1 MVP)

### 1. 온보딩 (최초 1회)
- 토스 프로필 API로 나이/연락처 자동 수집
- 추가 입력 필드:
  - 거주지: 시/도 → 시/군/구 (연계 드롭다운)
  - 취업상태: 재직 / 구직 / 학생 / 프리랜서 / 기타
  - 소득분위: 중위소득 기준 선택 (모름 옵션 포함)
- 저장: 토스 미니앱 로컬스토리지 (서버 저장 불필요)

### 2. 홈 화면
- 상단: "OOO님께 맞는 정책 N개 발견" 요약 카드
- 카테고리 탭: 전체 / 주거 / 취업·창업 / 금융 / 교육 / 복지·문화
- 최근 마감 임박 정책 배너

### 3. 정책 리스트
- 카드 형태:
  - 정책명, 주관기관, 지원금액/혜택 요약
  - 신청 마감일 (D-N 표시)
  - 자격요건 충족 여부 뱃지
- 필터: 지역, 카테고리, 신청가능 여부
- 무한스크롤 페이지네이션

### 4. 정책 상세
- 섹션: 지원내용 / 지원대상 자격 / 신청기간 / 신청방법 / 필요서류
- 자격 체크리스트: 내 프로필 기준 항목별 ✅ / ❌ 표시
- 하단 고정 CTA: [신청하기] → 공식 사이트 In-App Browser 연결

### 5. 내 정책 저장함
- 북마크한 정책 목록
- 신청 완료 체크 기능
- 마감일 기준 정렬

## 데이터 흐름

```
사용자 프로필 (로컬: 나이/지역코드/취업상태/소득)
        ↓
BFF /api/policies?age=25&zipCd=11110&jobCd=...&page=1
        ↓
온통청년 getPlcy 호출 (apiKeyNm + zipCd/lclsfNm/plcyKywdNm 등)
        ↓
BFF 후처리 필터링:
  - 연령: sprtTrgtMinAge ≤ 내나이 ≤ sprtTrgtMaxAge (sprtTrgtAgeLmtYn=N이면 무관)
  - 소득: earnMinAmt/earnMaxAmt vs 내 소득
  - 취업상태: jobCd 매칭
  - 마감: bizPrdEndYmd 기준 D-N 계산
        ↓
필터링·가공된 정책 목록 반환 → 미니앱 렌더링
```

자격 체크리스트(상세 화면)는 위 필드들을 내 프로필과 비교해 항목별 ✅/❌로 표시한다.

## 차별화 기능 (구현 완료)

1. **받을 수 있는 돈 합산** — `src/lib/youth/money.ts`가 `plcySprtCn` 텍스트에서 1인 지원금을 추정 파싱(만원 단위, 억원·예산 문맥 제외, 월 단위는 ×12 연환산). 적격 정책 합산을 `estimatedTotal`로 응답, 홈 상단 그라데이션 카드 + 정책 카드 `~N만원` 칩. 항상 "추정" 표기.
2. **서류준비 체크리스트** — 상세 화면에서 `sbmsnDcmntCn`을 항목 분해(`splitDocuments`)해 체크박스+진행률 바. 상태는 localStorage(`youth.docs.<plcyNo>`). 저장함 카드에도 준비율 표시.
3. **마감 타임라인** — 저장함을 D-day 오름차순 정렬, D-7 이내 빨강 강조. 홈 상단에 저장 정책 중 D-14 이내 "마감임박" 가로 스크롤. (푸시 알림은 앱인토스 SDK 연동 후 Phase 2)
4. **3문답 온보딩 진단** — 나이→지역→취업/소득 스텝 UI 후 "신청 가능 N개 / 약 M만원" 진단 리포트.

## 앱인토스 출시 절차

앱인토스는 직접 개발한 앱에 토스 SDK를 붙여 빌드 번들을 업로드 → 검수 → 출시하는 구조다.

1. **내 앱 직접 개발** (React 웹 → WebView)
2. **토스 SDK 연동** — 로그인/인증/결제 등은 SDK·TDS 컴포넌트로 적용
3. **콘솔에 서비스 기본 정보 등록 → 1차 승인** (약 1일 소요)
4. **빌드 번들 업로드 → 출시 검수**
5. **(수익화 시) 사업자 번호 등록 + 정산 승인 → 2차 승인**
6. **출시 검수 체크리스트 준수** — 디자인 가이드, 내비게이션 바, 등급 표기 등
