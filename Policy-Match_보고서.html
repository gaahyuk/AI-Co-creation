1. 프로젝트 개요

1.1 프로젝트명

Policy-Match: 청년 정책 매칭 플랫폼

1.2 프로젝트 설명

2026년 7월 (진행 중)

5. 발견된 문제점

5.1 TypeScript 타입 오류 (심각도: 높음)

**문제**: ``` 파일: src/app/api/policies/[id]/detail/route.ts (라인 8, 16) 파일: src/app/api/documents/[id]/file/route.ts (라인 8, 15) ``` **증상**: `RouteContext<"...">` 타입이 정의되지 않음 - Next.js 16.2.10에서 동적 라우트 매개변수 처리 방식 변경 - 현재 코드는 이전 버전 방식 사용 중 - 컴파일 오류 가능성 높음 **현재 코드 (오류)**: ```typescript ctx: RouteContext<"/api/policies/[id]/detail"> const { id: policyId } = await ctx.params; ``` **권장 수정**: ```typescript type Props = { params: Promise<{ id: string }> }; export async function GET(req: Request, props: Props) { const { id: policyId } = await props.params; ```

5.2 데이터 품질 이슈

